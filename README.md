# Student Depression Prediction

## Project Description

This project aims to predict whether a student reports experiencing depression based on demographic, academic, social, and health-related information.

Using student survey data, the project will examine how different student characteristics relate to reported depression.

## Project Goals

The primary goal is to successfully predict whether a student reports experiencing depression based on the following features:

- Gender
- Age
- Family background
- Relationship status
- Marital status
- Living style
- Current semester
- CGPA
- Friend circle
- Health condition
- Cost without study
- Home division

The prediction target will be the student's reported depression status.

## Data Collection Plan

The project will use the [Student Depression Dataset](https://data.mendeley.com/datasets/xn9cb5zpgg/2), obtained from Mendeley Data.

The dataset was collected through a survey distributed using Google Forms. Participants were students between the ages of 17 and 28.

The dataset contains student responses covering demographic, academic, social, and health-related characteristics, along with their reported depression status.

## Project Timeline

- **Weeks 1–2:** Explore and clean the dataset.
- **Weeks 3–4:** Prepare the data and perform exploratory analysis.
- **Weeks 5–6:** Train and experiment with machine learning models.
- **Week 7:** Evaluate results and identify useful patterns.
- **Week 8:** Finalize the project, documentation, and presentation.
